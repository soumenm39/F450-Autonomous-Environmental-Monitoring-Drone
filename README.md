# F450-Autonomous-Environmental-Monitoring-Drone
A custom-built F450-class quadcopter designed for environmental monitoring and atmospheric data collection.  The platform combines autonomous flight capability with onboard environmental sensors and telemetry systems for ecological and atmospheric research applications.

## Features

- F450 Quadcopter Platform
- RadioLink F722 Flight Controller
- u-blox NEO-6M GPS
- Return-to-Home Capability
- Environmental Sensor Payload
- Real-Time Telemetry
- Data Logging
- Expandable LoRa Communication
- Open Source Design

## Hardware Components

### Frame
- F450 Frame
- Landing Gear

### Propulsion
- DJI 2212 920KV Motors ×4
- SimonK 30A ESC ×4
- 11×4.7 Propellers

### Flight Control
- RadioLink F722 Flight Controller
- NEO-6M GPS Module

### Radio System
- RadioLink T8FB Transmitter
- RadioLink R8EF Receiver

### Power System
- Matek PDB-XT60
- 3S Li-ion Battery Pack
